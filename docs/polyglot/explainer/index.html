1. What I need from you

One real decision, in two parts. Phase 2 cannot start until it is settled — everything else can wait.

Decide before Phase 2

The contract is not finished being a contract

Phase 1 turned the code graph into a socket so a second tool (graphify) can plug in. The review's verdict was blunt and I agree with it: it is our own resolver's shape wearing an interface.

It proved that rather than arguing it. Someone built a second backend that satisfied the contract completely — and it crashed twice, then exited successfully having written no graph at all. I fixed the two crashes. The third thing is a design choice, not a bug. why it happened →

Part A — who saves the graph?

Right now saving the file, checking it is valid, and building the reverse index all live inside our own resolver. So a different backend can do everything right and still produce nothing, while reporting success. That is the same "confident empty answer" failure the whole project exists to remove.

I think this one is not really optional — without it the socket can only run the plug it was moulded around. But it is your call, because it means moving code. the detail →

Part B — does the graph track files, or symbols?

Today an edge is "file A depends on file B". graphify knows much more — which function calls which, which class extends which. Our contract has words for those but nowhere to put them, so they get flattened and thrown away.

Measured: our shape can express 2,102 of graphify's 5,027 real connections. It cannot express 58%.

  • Stay file-level, and say so Drop the words we cannot honour, and drop the per-edge "how sure are we" tagging from Phase 2's scope. Cheapest. Loses most of what graphify knows.
  • Make an edge an object now Instead of just a filename, an edge carries what kind it is and how it was found. There is one producer and one reader today, so this will never be cheaper than it is this week.
  • Defer it to Phase 3 Matches the original plan — but Phase 2 promises per-edge provenance it then cannot deliver, so the contract gets reopened anyway.
