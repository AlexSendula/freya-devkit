1. The decision you made, and what it cost

This section used to ask for one. You answered on 2026-08-20: both parts, plus a third thing you spotted that turned out to be the more serious of the two. All three are built. Phase 2 is unblocked.

Decided and shipped

The contract is finished being a contract

Phase 1 turned the code graph into a socket so a second tool (graphify) can plug in. The review's verdict was blunt and I agreed with it: it was our own resolver's shape wearing an interface.

It proved that rather than arguing it. Someone built a second backend that satisfied the contract completely — and it crashed twice, then exited successfully having written no graph at all. why it happened →

Part A — who saves the graph? The contract does, now.

Saving the file, checking it is valid and building the reverse index all lived inside our own resolver, so a different backend could do everything right and still produce nothing while reporting success. That is the same "confident empty answer" failure the whole project exists to remove.

A backend now produces nodes and edges and stops. Everything after that happens once, in one place, for every backend. A side effect worth naming: the contract's own validator had never actually run on a build. It runs on every one now, and writes what it finds into the artifact rather than only onto the stderr of the run that produced it. the detail →

Part B — what can one edge say? More than a filename, now.

An edge was a string: the path it pointed at. A string carries exactly one fact, so "A imports B" and "A re-exports B" were the same value, and "this function calls that function" could not be written down at all.

Measured: the old shape could express 2,102 of graphify's 5,027 real connections. It could not express 58%.

An edge is now an object carrying what kind of relation it is and how directly it was read out of the source. It already pays for itself before graphify arrives: a barrel file that only forwards a module is now distinguishable from one that actually uses it. the full trade-off →

I had titled this one "does the graph track files, or symbols?", which was wrong and confusing — you said so. The nodes are still files. What changed is what a single edge between them is allowed to say. Symbols are Phase 3, and this is what makes room for them.

Part C — your objection, which was the sharpest of the three

You pushed back on a default I had changed, on the grounds that we cannot know what some other project keeps in a folder called docs/. I partly disagreed with the fix you proposed and then went looking, and found the real problem is worse than the one you described: a project could not disagree with the defaults at all.

Marking a folder as source was accepted, written to disk, and then silently overruled — the filter never read those verdicts. So a wrong default was not merely a wrong default, it was unfixable. It can be argued with now. what changed exactly →
